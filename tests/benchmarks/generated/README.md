# Generated Synthetic Network Suite

Synthetic SWMM5 `.inp` files generated by
[SWMManywhere](https://github.com/ImperialCollegeLondon/SWMManywhere) from
OpenStreetMap street graphs and SRTM elevation data.

Each network provides a realistic drainage topology for integration testing and
iteration-count benchmarking of the spectral coarse correction preconditioner.

**The `.inp` files are NOT stored in this repository** — they range from 4–17 MB.
They are generated locally into `~/Projects/swmm6_generated_networks/` and are
fully reproducible from the script below.

The script writes output to `~/Projects/swmm6_generated_networks/` by default.

## Generating / regenerating

Requires the `swmmanywhere` conda environment (see below).

```bash
# Generate all 7 networks:
/Users/corinnewiesner/anaconda3/envs/swmmanywhere/bin/python3 \
    openswmm.engine/tests/benchmarks/generated/generate_suite.py

# Regenerate specific networks:
python3 generate_suite.py --networks 01 04

# Use a different output directory:
python3 generate_suite.py --output-dir /path/to/networks

# Preview configs without running:
python3 generate_suite.py --dry-run
```

The `_work/` directory caches downloaded OSM and DEM data by bbox hash;
re-running the same network reuses cached downloads (no re-download).

## Topographic note

Ultra-flat cities (Amsterdam, Rotterdam, Bruges, New Orleans) fail with
`"No non nan pipes designed"` because near-zero surface slope drives Manning
velocity → 0, which enters `V**1.31 → NaN` in the cost function. All seven
cities above have enough topographic relief to pass.

## SWMManywhere installation

```bash
conda create -n swmmanywhere python=3.11
conda activate swmmanywhere
conda install -c conda-forge numba pyflwdir
pip install swmmanywhere==0.2.2
```

Networks were generated with **SWMManywhere 0.2.2** and are in SI units
(`FLOW_UNITS = LPS`, `FLOW_ROUTING = DYNWAVE`).
