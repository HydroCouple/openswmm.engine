# R4 physical-area ET qualification

This is a qualified internal source-stage extension, **not production activation, GUI result implementation or R4 completion**. It follows the already approved [area/ET/GUI contract](../../../../openswmm.gui/workplans/SURFACE_SUBSURFACE_R4_AREA_REVIEW_2026-10-05.md). [The implementation note](../../../plans/SURFACE_PROCESS_R4_AREA_ET_2026-10-06.md) gives the supported profile, actual changes and remaining gates.

**253 cases pass in 12 isolated suites**, including 16 added cases and all 53 updated node-storage/Richards controls. Qualification uses current committed parent `b26b0a25`, Release, 2D/GeoPackage/HDF5 on, LTO/Python/GPU/HydroCouple off. This is not a complete qualification of all work saved by that aggregate parent.

- `baseline.json`: parent and before-edit hashes; local `before/` copies preserve the exact source baseline.
- `source-audit.json`: exact qualification tree and source/build hashes; unchanged node, Richards and SIGMA controls. The configured build's source copy is reused, with all archived tracked files synchronized. Final documentation-only changes are recorded separately.
- `case-counts.json`, `qualified-results.json`, `qualified-cases/`, `qualified-tests.log`: the final successful run. The earlier `first-*` and `final-*` records remain local; only `qualified-*` contributes to the case count.
- `prepare_source.py`, `run_tests.py`: reproducible exact-tree preparation and isolated suite runner. Git snapshot preparation requires access to the repository object database; it does not alter the shared index or branch. Local archives/build products/temporary indices are ignored.
- `sigma_probe.cpp`, `sigma-probe.jsonl`, `sigma-baseline-audit.json`: an unresolved existing moving-table SIGMA conservation gap, reproduced without a common source stage or area-budget call, including cases with **no ET demand**. `fireCell` and `SigmaColumn` match the parent. The maximum no-ET residual is 0.984802466 m³. The common stage now refuses SIGMA receivers until this is corrected and qualified. Fixed-table SIGMA area-budget tests do not certify these failing table dynamics.

The first pass also exposed two fixture assumptions: date-encoded PET records differ from idealized integer seconds at floating-point precision, and bounded pervious runoff can retain a minute water residue. Final tests integrate the actual stored timestamps and check the residue at numerical roundoff, without relaxing atmospheric or water closure. ET-only stress checks isolate extraction from table movement. The SIGMA failure is retained as a required corrective phase, rather than counted as a passing conservation result.

No new GUI parameter, forcing prescription, timestep knob, SDK installation or executable deployment is introduced. Existing approved Remap inputs/editors and potential/actual/unused/pending result design still apply. Source ET receipts are last-interval diagnostics; durable provenance and saved runtime views remain unimplemented. The router gate, fully inside/non-lumped restrictions, transport/runtime-provider/return-water/restart refusals and trench/barrel store profile remain in force. COVERED cases use the existing kernel snapshot flag, not new model authoring.
