# R4 surface ownership authoring — 2026-10-05

The user approved R4-1 through R4-4 with “Approve and proceed.” This implements the first authoring/resolver tranche of the [approved review](../../openswmm.gui/workplans/SURFACE_SUBSURFACE_R4_AREA_REVIEW_2026-10-05.md). Runtime recharge and scheduler qualification remain subsequent work under that approval.

The opt-in `[2D_SURFACE_OWNERSHIP]` section stores `Subcatchment SUBCATCH UNIFORM`. Its absence retains the existing formulation. Authored ownership alone does not create an aquifer. An enabled 2D aquifer in MODE MESH and active routing are required for review. The legacy groundwater ignore flag can be automatically true when no lumped aquifer exists; spatial aquifer review follows its separate 2D enable setting.

`resolveSurfaceOwnership` is the common read-only resolver. It allocates LID unit count × per-unit area first, applies impervious fraction to the remaining area, and clips triangulated simple source polygons against convex engine cells. Areas are SI. Declared acres use exactly 43560 ft² and hectares use exactly 10000 m²; existing runoff's historical land-area conversion is not silently normalized. That legacy conversion seam must be qualified when runtime source volumes are integrated. Concave polygons and disconnected clipped portions are supported. Holes/multipart rings, self-intersections, missing/nonfinite/degenerate geometry and nonconvex cells have explicit blocking diagnostics. A relative area tolerance of 1e-8 (or the geometry roundoff bound if larger) reconciles declared/polygon area; it never changes an authored area.

Lumped groundwater keeps recharge precedence while consuming its reviewed weather footprint. Sealed LIDs retain weather ownership and have zero native-bottom eligible area. Source shares include outside area; mesh remaining weather is a geometric proposal, not an applied weather source. The connected ownership region is traversed by source/cell adjacency; unreviewed peers and overlapping physical polygons block it. An x sweep skips disjoint polygon pairs. Progress/cancellation leaves records unchanged.

The public C API returns source objects, cell/source shares, remaining mesh weather area, diagnostics and a current-input revision token. Preview requires editing state and advances nothing. Replacement validates the proposed complete set and token before one assignment. Empty replacement restores absence, including Undo. Token inputs include CRS, mesh coordinates/connectivity, source area/polygon/LID assignments, transport/process flags, exact receiving configuration and current ownership records. Hosts must also validate their active GUI mesh and coordinate system against the engine snapshot.

INP writes the optional section without enabling groundwater. GeoPackage stores an optional authoritative section bundle together with the receiving aquifer; its numbers use full double precision. The new precision path exposed and fixed unsigned field-padding overflow. Its round-trip test also exposed an existing early return that skipped quad-only meshes in GeoPackage. The bulk coordinate reader now has the same editing-state geometry guard as the single-coordinate reader.
